# Changelog

All notable changes to the `dynamic_shape` package will be documented in this file.

## 1.0.0

- Initial stable release of the Universal Dynamic Shape Engine for Flutter.
- **28 Parameterized Geometries**:
  - `folderTab`, `notchedBadge`, `sideTab`, `steppedCorner`, `ticketScallop`, `postageStamp`, `zigzagCut`, `arch`, `hexagonSoft`, `chamferDiagonal`, `organicBlob`, `scallopedPetal`, `smoothRounded`, `asymmetricCard`, `capsule`, `waveEdge`, `cloud`, `speechBubble`, `shield`, `diamond`, `octagon`, `waveCut`, `concaveRounded`, `convexRounded`, `squircle`, `parallelogram`, `ribbon`, `bookmark`, and `customBezier`.
- **20 Border Styles**:
  - Solid, dashed, dotted, double stroke, gradient, neo-3D, glow, animated gradient sweep, neon pulse, metallic finishes (gold, silver, bronze, platinum, copper, titanium), rainbow prism, multi-layer offsets, corner-only accents, and hand-drawn sketch styles.
- **Background Effects & Procedural Textures**:
  - 12 procedural background effects including aurora borealis, cyber grid, mesh gradient, particle constellation, holographic shimmer, and procedural patterns (dots, stripes, grids, waves).
- **Physics & Motion Engine**:
  - Spring simulations, haptic interactions, magnetic hover, swipe morphing, pressable tactile bounce, and reduced motion accessibility.
- **Smart Layout Engine**:
  - Geometry-aware safe insets, RTL auto-mirroring, inscribed collision-free rects, and touch target accessibility validation (min 48x48 dp).
- **Comprehensive Widget Library**:
  - `AnimatedShapeCard`, `ShapeProgress`, `ShapeDivider`, `ShapeAppBar`, `ShapeNavigationBar`, `ShapeBottomSheet`, `ShapeDialog`, `ShapeTooltip`, and `ShapeContainerGroup`.
- **Interactive Developer Tools & Presets**:
  - `ShapePlayground` interactive live studio, code generation, and 10 production-ready presets.
